# ox1audio

Build Mixel apps: the Python SDK and the `mixel` command.

```bash
uv tool install ox1audio
mixel new "My App"
```

The guides and the reference are at [docs.0x1audio.com](https://docs.0x1audio.com). To work on the SDK itself, see [CONTRIBUTING.md](CONTRIBUTING.md).
